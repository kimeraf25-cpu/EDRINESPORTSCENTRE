EDRINE SPORTS WEBSITE
This is an 8-page responsive sports website.

Pages:
1. index.html - Home
2. football.html - Football
3. basketball.html - Basketball
4. netball.html - Netball
5. athletics.html - Athletics
6. news.html - Sports News
7. gallery.html - Gallery
8. contact.html - Contact

To open:
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html and choose Open with Live Server, or double-click index.html.

Images are real sports photographs hosted by Unsplash. Internet is required to display them.
Before publishing, replace YOUR-EMAIL@example.com in contact.html with your email address.
Keep index.html in the main folder when uploading to GitHub Pages.
